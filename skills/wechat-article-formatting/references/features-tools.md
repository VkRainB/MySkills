## Markdown 转公众号

### Markdown Nice

| 属性 | 说明 |
|------|------|
| 网址 | mdnice.com |
| 特点 | Markdown 写作，一键转换公众号格式 |
| 价格 | 免费 |
| 推荐度 | ⭐⭐⭐⭐⭐（技术类文章） |

**适用人群：**
- 程序员/技术作者
- 习惯 Markdown 写作的人
- 需要代码高亮的文章

**使用流程：**
```markdown
1. 在左侧编写 Markdown
2. 选择主题样式
3. 右侧实时预览效果
4. 点击「复制」
5. 粘贴到公众号后台
```

**支持的语法：**
- 标题（H1-H6）
- 列表（有序/无序）
- 代码块（语法高亮）
- 表格
- 图片
- 引用
- 粗体/斜体

### 封面图制作

```markdown
推荐尺寸：
- 头条封面：900 × 383 px（2.35:1）
- 次条封面：500 × 500 px（1:1）

设计要点：
1. 主体居中（避免被裁剪）
2. 文字大而少
3. 对比度高（小图也清晰）
4. 风格统一（形成品牌）
```

## 效率提升技巧

### 建立素材库

```markdown
组织方式：
素材库/
├── 分隔线/
├── 标题样式/
├── 引用框/
├── 代码框/
├── 常用封面/
└── 品牌素材/
```

### 创建样式模板

在常用编辑器中保存自己的样式模板：

1. 统一的标题样式
2. 统一的正文样式
3. 常用的组件样式
4. 品牌色彩方案

### 批量处理流程

```markdown
1. 批量写作（Notion/语雀/Markdown）
2. 批量排版（套用模板）
3. 批量压缩图片（TinyPNG 批量上传）
4. 批量预览检查
5. 定时发布
```
